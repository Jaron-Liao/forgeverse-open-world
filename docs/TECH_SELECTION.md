## 3. 技术选型（决策 + 理由）

| 维度 | 选型 | 理由（一句） |
|---|---|---|
| 引擎 | Three.js r160 WebGL（本地 vendor） | 沙箱无 GUI 装不了 Unity，且网页即可运行、跨端分享 |
| 场景建模 | 程序化几何 + PBR + 顶点色渐变 | 零外部依赖、可参数化，逼近写实层次感 |
| 资产接入 | GLB/GLTF 导入通道 | 混元3D/Tripo/Blender 统一经此进资产库 |
| 地形 | 种子化分块 + 噪声 | 无限地图 + 可复现 |
| 数据 | 腾讯云 wb_saves（RLS） + 本地文件 | 用户隔离 + 离线可用 |
| 跨端 | PWA（响应式 + 可安装） | 一套代码覆盖电脑/手机 |
| 云部署 | GitHub Pages（静态）+ 腾讯云数据 | 免费托管 + 合规数据 |
| 错误处理 | 边界校验、友好提示、降级 | 不信任客户端输入，失败不静默 |

## 4. "Q版工作台" 与 "3A 质感" 的关系（关键澄清）

这两个词不矛盾，是**两个不同层**：

- **Q 版工作台 = 交互层**：图标、按钮、面板保持圆润可爱的 Q 版风格，降低操作门槛、亲和力强（现有王者风格皮肤即此层）。
- **3A 质感 = 渲染层**：3D 视口里的世界要写实——真实光照、材质、阴影、地表细节、天气氛围。

本项目做法：**UI 保持 Q 版易读，视口追求写实**。两者通过统一的暗金配色衔接。

## 5. 当前到达的级别（诚实标注）

| 目标 | 当前级别 | 说明 |
|---|---|---|
| 3A 写实 | ⭐⭐ 准写实近似 | 程序化几何 + PBR + 顶点色层次，非贴图扫描级 |
| 世界模型整体感 | ⭐⭐ 世界一致 | 统一天空/光色/天气/昼夜 + 三环境分层，非 AI 世界模型 |
| 真实大型开放世界 | ⭐⭐⭐ 可运行开放场景 | 种子无限地形 + 分层资产 + 漫游 |
| 史诗级动态 | ⭐⭐ 有动态天气/昼夜 | 粒子/光色/雾实时变化 |

> 真正的 3A 贴图扫描资产、HDRP 级光照烘焙、AI 世界模型需要 Unity/Unreal + 专业美术资产，属于后续里程碑（见项目报告）。

## 6. 抖音/B站 创作者方法（筛选后）

采纳：程序化地形教程思路、PBR 材质调参、天气氛围分层、前后期对比展示方法。
过滤：宣称"一键生成 3A"的不可行方案、需付费私域工具、涉及盗用游戏资产的不合规内容。

## 7. 混元3D / Tripo 使用路径

1. 在 https://3d.hunyuan.tencent.com/ 文生/图生 3D → 导出 GLB
2. 或 https://studio.tripo3d.com/ 生成角色/场景 → 导出 GLB
3. 工作台左侧「导入 GLB/GLTF」→ 进资产库 → 放置到场景
4. 网页公开 API 未确认，当前为半自动（平台生成 + 手动导入）
