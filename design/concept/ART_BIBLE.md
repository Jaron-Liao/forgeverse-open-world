## 1. 视觉身份九节

### 1.1 核心情绪 · Core Emotion

一句话定位：**「玄墨为纸，鎏金为骨，一束天光落在你的造物上。」**

ForgeVerse 是造物工作台，视觉要同时传达两种看似矛盾的情绪：

- **庄重感（史诗层）**：进入世界管理页时，像翻开一卷东方典籍、推开一扇殿门——安静、深邃、有分量。这是"黑神话质感"要借的**情绪**，不是它的美术资产。
- **亲和感（操作层）**：一旦进入建造，工具要圆润、轻快、顺手，点下去有"糖块般"的踏实反馈——这是 Q 版简约的用武之地。

情绪公式：
> **舞台写实，操作 Q 版；背景收，控件放；光比强，颜色稳。**

三个锚点词（供 AI 生成提示词统一使用）：`Oriental dark-gold`、`Cinematic chiaroscuro`、`Chibi-friendly roundness`。

### 1.2 色彩系统 · Color System

> 全部为 **sRGB hex**。当前 `css/3d.css` 存在**双色系冲突**：早期蓝紫（`--acc:#5cc8ff;--acc2:#ff5fa2`）与 v5 王者暗金（`--gold:#e8c37a`）并存，导致入口出现"暗金边框 + 蓝紫渐变按钮"的割裂。**本次统一收敛到暗金体系，蓝紫仅保留为赛博场景与交互高亮的局部色。**

### 1.3 字体与字号层级 · Typography

**离线约束**：不加载任何网络字体；使用系统字体栈。东方感通过**衬线标题 + 字距**获得，正文保持无衬线可读性。

```
--font-display: "Songti SC","STSong","SimSun","Noto Serif CJK SC",serif;  /* 东方标题 */
--font-ui: "PingFang SC","Microsoft YaHei","Segoe UI",system-ui,sans-serif; /* 界面正文 */
--font-num: "DIN Alternate","Bahnschrift","Segoe UI",sans-serif;  /* 数字/HUD */
```

| 层级 | 字号 / 行高 | 字重 | 字距 | 字体 | 用途 |
|---|---|---|---|---|---|
| H0 世界标题 | 32 / 42px | 700 | 3px | display | 世界管理页顶栏主标题 |
| H1 分区标题 | 22 / 30px | 700 | 2px | display | 模态标题、面板大标题 |
| H2 卡片标题 | 16 / 24px | 600 | 1px | ui | 场景卡名、分组标题 |
| H3 小标题 | 14 / 20px | 600 | 0.5px | ui | 表单标签、面板小标题 |
| Body 正文 | 13 / 20px | 400 | 0 | ui | 按钮、列表、输入 |
| Caption 辅助 | 12 / 18px | 400 | 0 | ui | 说明文字（下限） |
| Num 数字 | 13 / 18px | 600 | — | num | FPS、计数、等级 |

**规则**：
- 正文**不得小于 12px**（可访问性下限，见第 7 节）；原 CSS 中 `.tip{11px}`、`.ic-meta{11px}` 等需上调或降级为纯装饰。
- 中文标题用 `letter-spacing:2~3px` 制造"碑刻感"，但正文不加字距以免阅读疲劳。
- 不使用 emoji 作为标题主角（现有 `🌍 新建你的世界`、`⚔ 操作台` 需去除，见第 8 节）。

### 1.4 图形语言 · Shape Language

三种基本形，对应三种心理暗示：

1. **切角多边形（写实务）** — 用于**容器/框架**：世界管理页大卡、面板、视窗边框。沿用现有 `clip-path:polygon(0 0,calc(100% - 14px) 0,100% 14px,100% 100%,14px 100%,0 calc(100% - 14px))`，切角尺寸随容器放大（大卡 18px，面板 12px）。切角是"东方建筑/碑牌"的抽象，比纯圆角更有庄重感。
2. **圆角矩形（Q 版务）** — 用于**控件**：按钮、输入框、图标底、胶囊标签。圆角 `10~14px`，大按钮可到 `16px`。圆润 = 亲和、可点击。
3. **朱砂印章（点睛务）** — 用于**状态印记**：选中态角标、"推荐/进入"印、等级徽记。小尺寸方形红底金字，旋转 -6°，模拟篆刻。

**边框规范**（三层描边营造"鎏金包边"）：
```
外描边：1px solid rgba(232,195,122,.55)
内高光：inset 0 1px 0 rgba(255,223,158,.22)   /* 顶部受光 */
辉光：  0 0 0 1px rgba(10,11,16,.9), 0 8px 32px rgba(0,0,0,.55)
```
> 关键：**双色描边**（金 + 墨）比单金线更有"镶嵌"质感，这是从电影级材质借来的原则。

### 1.5 材质与光泽 · Material & Gloss

- **面板材质**：`ink-700/600` 半透明 + `backdrop-filter:blur(12px)` 毛玻璃，叠一层极淡的**噪点纹理**（CSS `repeating-linear-gradient` 或内联 SVG noise，透明度 ≤3%），模拟宣纸/磨砂金属的微表面——这是"材质真实感"的廉价实现。
- **金属质感**：鎏金控件用 `linear-gradient(135deg,gold-300,gold-500,gold-700)` 三段渐变，配合顶部 1px 内高光，呈现"受光的金"。避免纯扁平金色。
- **光泽扫过（sheen）**：高价值元素（主 CTA、场景卡 hover）可加一道 45° 白色渐变扫光，hover 时从左上扫到右下，时长 600ms，**每元素仅 hover 触发一次**，克制使用。
- **墨色阴影**：所有浮层阴影偏冷黑 `rgba(0,0,0,.55)`，不用纯黑；阴影距离大而柔（`0 12px 40px`），营造"悬浮于暗室"的景深。
- **禁止**：霓虹描边堆叠、大面积纯白发光、多重彩色 shadow（旧 `.logo` 的 `drop-shadow` + 强调色叠加要收敛）。

---

### 1.6 空间与留白 · Space & Quiet

- **8px 基准网格**：所有间距为 8 的倍数（8/16/24/32/48）。现有 `gap:6px/14px` 属历史遗留，新组件统一到 8 网格。
- **克制留白**：世界管理页遵循"**三分法留白**"——标题区占约 20%，卡片区占约 60%，底部留白约 20%。宁可太空，不可太满。暗部大面积留空正是"黑神话质感"的关键，不要用说明文案填满。
- **安全边距**：全屏页面内容距视口边 ≥48px（大屏）/ ≥24px（小屏）。
- **视觉重心**：每屏**只有一个**最强焦点（世界管理页 = 选中场景卡；建造页 = 3D 视窗）。其余元素降级为"暗示"。

### 1.7 动效节奏 · Motion Rhythm

四档时长，全部用 `cubic-bezier(.22,.61,.36,1)`（顺滑减速，Q 版"糖块"手感）：

| 档位 | 时长 | 场景 |
|---|---|---|
| 微反馈 tap | 120ms | 按钮按下、图标点击 |
| 过渡 hover | 200ms | 边框变色、轻微上浮 `translateY(-2px)` |
| 面板进出 | 320ms | 模态淡入、侧栏收起、卡片 stagger |
| 场景切换 | 480ms | 世界管理页进入建造、视窗淡入 |

**规则**：
- 卡片入场用 **stagger 60ms** 依次浮现（四场景卡依次点亮，营造"展开卷轴"感）。
- 视窗内 3D 相机无操作时不自动旋转（避免眩晕）；氛围粒子可极缓飘动。
- **所有动效须响应 `prefers-reduced-motion:reduce`** → 时长归零/改为瞬变（见第 7 节）。
- 禁止：弹跳 `bounce`、无限循环的高频闪烁（现有 `.pet{bob 2.4s infinite}` 保留但幅度需更小、且尊重减弱动效）。

### 1.8 图标风格 · Iconography

- **风格**：**面性圆润图标**（filled-round），线性图标作补充。笔画端点圆角 `stroke-linecap:round`，转角圆润——Q 版亲和。
- **网格**：24×24 基准，安全区 20×20，视觉重心居中。
- **配色**：默认 `txt-2`，激活 `gold-300`，危险 `cinnabar`；图标**单色为主**，最多双色。
- **现状问题**：当前大量使用 emoji（🛠🎨⛰🌿🌳🪨…），风格不统一、跨平台渲染不一致、无法着色。**迁移策略**：见第 6 节资产清单，优先替换高频图标（模式切换、顶栏工具）为统一 SVG 图标集；低频可暂留 emoji 过渡。
- **"开始建造"箭头**：用自定义 `→` 细线箭头，不用 emoji。

## 2. 「黑神话质感 × Q 版简约」融合原则

### 2.1 一句话分工

> **写实质感负责"氛围与骨架"（背景、光、材质、边框、景深）；Q 版简约负责"操作与反馈"（按钮、图标、卡片交互、微动效）。**

### 2.2 写实层 vs Q 版层 分工表

| 视觉元素 | 采用 | 具体做法 | 理由 |
|---|---|---|---|
| 世界管理页背景 | **写实** | 分层景深、雾气、体积光、暗角 | 营造史诗"殿门"感 |
| 3D 视窗内世界 | **写实** | 现有 PBR + ACES 色调映射 + Bloom + 环境反射 | 造物本身要真实可信 |
| 卡片缩略图 | **写实意象** | 微缩风景，真实材质与光，但构图简洁 | 传达场景氛围 |
| 容器/大卡边框 | **写实** | 切角多边形 + 鎏金双层描边 + 微噪点 | "碑牌/金属包边"质感 |
| 光效/阴影 | **写实** | 强光比、冷黑柔阴影、轮廓光 | 电影级光比 |
| 按钮 | **Q 版** | 圆角、糖块式按下反馈、柔和渐变 | 亲和、可点性强 |
| 图标 | **Q 版** | 面性圆润、24 网格、单色 | 清晰、统一 |
| 卡片 hover/选中 | **Q 版** | 上浮 2px、快速高亮、印章角标 | 轻快反馈 |
| 文字排版 | **Q 版** | 无衬线、留白充足、层级清晰 | 易读、现代 |
| 造物精灵/宠物 | **Q 版** | 圆润卡通形象、小幅浮动 | 情感亲和锚点 |

### 2.3 三条融合铁律

1. **同色不同质**：写实层与 Q 版层共享同一套暗金色板（1.2），靠**质感**（渐变/噪点/光比）而非**色相**区分层次。这样既统一又不单调。
2. **暗框亮心**：框架永远暗（玄墨+暗金），焦点控件才亮（朱砂/亮金/Q 版圆角）。避免"整体亮"导致的廉价感。
3. **景深让位操作**：背景景深做得再电影级，一旦鼠标进入控件区，控件必须"浮"在最前、绝对清晰——**操作优先级高于氛围**。

### 2.4 版权安全边界

- ❌ 不使用任何游戏的具体角色、武器、UI 贴图、云纹/龙纹原图、书法字体文件。
- ✅ 纹样一律用**原创几何抽象**：切角、直线回纹、圆点阵列、对称金线。
- ✅ "东方感"通过**配色 + 光比 + 字距 + 留白**传达，不靠具体符号移植。

## 3. 全屏世界管理页视觉层级规范

> 目标：把当前 `index.html` 的 `#intro` 小弹窗，升级为**全屏世界管理页**——像翻开典籍、推开殿门。四个场景以选项卡片呈现。

### 3.1 背景层次（由远及近，共 4 层）

| 层 | 内容 | 视觉参数 |
|---|---|---|
| L0 底 | 玄墨纯色 | `#0A0B10` |
| L1 氛围 | 极暗的**放射状光晕**（从页面上方 1/3 处透下的"天光"） | `radial-gradient(ellipse at 50% 18%, rgba(232,195,122,.10), transparent 60%)` |
| L2 景深 | 远/中/近三层剪影：远山墨色剪影（最淡）、中景雾带、近景桌面/案台暗纹 | opacity 0.06~0.14，`blur(2~8px)`，纯 CSS/SVG 程序化，无外部图 |
| L3 内容 | 标题区 + 场景卡 + 底部 | 清晰、无模糊 |

- 加**暗角 vignette**：四角径向压暗 `rgba(0,0,0,.5)`，强化"暗室一束光"。
- 层次间靠**明度 + 模糊度**拉开，不靠色相——保持克制。

### 3.2 卡片排布 — 三种布局方案的视觉建议

> 四场景卡（草原/雪原/沙漠/赛博）提供三种候选，视觉推荐 **方案 A** 为默认。

**方案 A · 并列四联（推荐）**
- 四张等宽卡横向排列（`grid-template-columns:repeat(4,1fr)`），桌面端单屏展示。
- 视觉：像"四扇门并列"，一目了然，选择成本最低。
- 窄屏（<900px）自动降为 2×2。
- 适用：首次新建世界，强调"四选一"。

**方案 B · 主次聚焦**
- 当前 hover/默认场景卡放大为 1.4× 主卡，其余三张缩小环绕。
- 视觉：戏剧性强，焦点突出，但信息密度高、实现复杂。
- 适用：想强化"推荐场景"或做视觉演出时。

**方案 C · 横向长廊**
- 卡片横向可滚动，一次露 2~3 张，带左右箭头。
- 视觉：卷轴展开感，可扩展更多场景。
- 适用：未来场景数量 >4 时。

> **决策**：本期用方案 A；在文档注释中预留 B/C 的 CSS 钩子（`data-layout="row|focus|carousel"`），便于后续切换。

### 3.3 场景卡状态规范（四态）

单张卡结构：**缩略图区（上 62%）+ 信息区（下 38%）**，卡名 + 一句氛围词。

| 状态 | 视觉表现 |
|---|---|
| **默认 Default** | 切角容器、暗金 1px 描边（55% 透明）、场景主色缩略图、卡名 `H2`、无辉光 |
| **悬停 Hover** | `translateY(-4px)`、描边转 `gold-300` 100%、叠 45° 一次扫光、缩略图轻微放大 1.03、阴影加深 |
| **焦点 Focus** | `outline:2px solid jade;outline-offset:3px`（键盘导航可见），不改其他属性 |
| **选中 Selected** | 描边 2px `gold-300` + 常驻柔辉光 `0 0 24px gold-glow` + 右上角**朱砂印章**（"选"字或 ✓）+ 缩略图亮度 +8%；其余卡降饱和 20% 作陪衬 |

> 陪衬处理是"电影级光比"在 UI 上的体现：**选中即打光，未选中即入影**。

### 3.4 焦点态与光效

- 页面载入：标题先浮现（320ms），四卡 stagger 60ms 依次点亮，最后默认场景（草原）落印选中。
- 天光 L1 层在卡片选中时，光晕中心**轻微移向该卡**（CSS 变量驱动 `--light-x`），实现"追光"——低成本的景深互动。
- 底部世界名输入：暖金细线下划线输入框（非白底方块），聚焦时下划线由 `gold-700` 渐变到 `gold-300`，删除白底（见 3.5）。

### 3.5 需废弃的旧样式（对应第 8 节）

- `.card` 白/亮蓝渐变底 → 改玄墨半透明 + 切角。
- `#worldName` 白底输入框 → 改暗色下划线输入框。
- `.primary` 蓝紫渐变 → 改朱砂→鎏金渐变。
- `.tip` 底部说明文案 → 删除（见第 8 节）。

## 5. 独立渲染视窗美术规格

> 用户要求"独立渲染视窗"：3D 世界在独立视窗内渲染，与工作台 UI 分离。技术由程基岩实现（Three.js 独立 renderer/canvas），本节定其**视觉衔接**规范。

### 5.1 视窗边框

- **双层框**：外层切角容器（`ink-900` 底 + 2px `gold-700` 描边）+ 内层 1px `gold-500/40%` 细线，间距 6px，形成"画框中的画框"。
- **四角金饰**：四个切角处各加一小段 45° 金线（8~12px），强化"取景框/碑框"感（纯 CSS `::before/::after` + 渐变）。
- **顶部铭牌**：视窗左上贴一枚小铭牌，显示当前世界名 + 场景图标，`H3` 字号、`gold-300` 字、半透明墨底——像"画卷题签"。

### 5.2 光效

- 视窗**内边缘**加极淡的内阴影 `inset 0 0 60px rgba(0,0,0,.5)`，让 3D 画面"沉入"框内，与 UI 拉开层次。
- 视窗**外边缘**加柔和金色辉光 `0 0 40px rgba(232,195,122,.12)`，暗示"这是焦点舞台"。
- 视窗内 3D 渲染沿用现有电影级管线（ACES + Bloom + 环境反射），**不在 CSS 层再加滤镜**，避免双重处理导致过曝。

### 5.3 与工作台 UI 的视觉衔接

- 视窗边框材质、切角角度、描边色**必须与左侧资产栏、右侧检查器一致**（同一套 `--line`/gold 变量）——视窗是"舞台"，侧栏是"后台"，同属一座建筑。
- 视窗与侧栏之间用 24px 统一间距，背景同为 `ink-800`，无硬分隔线（靠明度差区分层级）。
- 建造页顶栏、底栏保持现有暗金皮肤，但需按第 1.2 节收敛蓝紫色残留。

### 5.4 尺寸与响应

- 桌面：视窗占据侧栏之间的主区域（`inset:topbar 68px / leftbar+gap / rightbar+gap / bottombar+gap`）。
- 侧栏收起时视窗**平滑扩展**（320ms）填充空间，边框随之过渡——强化"顺滑"手感。
- 移动端：侧栏改为抽屉，视窗全宽。

## 7. 可访问性分级 · Standard

**选定分级：Standard（标准级）** —— 在不牺牲视觉方向的前提下，覆盖绝大多数用户的可访问需求，是水平衡"史诗质感"与"易用性"的合理档位。

| 特性 | 是否纳入 | 具体要求 |
|---|---|---|
| 对比度 AA | ✅ | 信息文字 ≥4.5:1，大字/图形 ≥3:1（按 1.9 红线） |
| 键盘可达 | ✅ | 所有可交互元素可 Tab 聚焦；`focus-visible` 用 jade 2px 外环；模态打开时焦点锁入、ESC 关闭 |
| 字号下限 | ✅ | 功能文字 ≥12px；提供 UI 缩放支持到 200% 不破版 |
| 色盲友好 | ✅ | 状态**不单靠颜色**：选中态同时有印章/描边粗细/亮度变化；赛博青紫对红绿色盲需靠明度区分 |
| 动效减弱 | ✅ | `@media(prefers-reduced-motion:reduce)`：动画时长→0.01ms、关闭视差/stagger/扫光/浮动 |
| 语义标签 | ✅ | 输入框 `<label>` 关联、按钮 `aria-label`、场景卡 `role="radiogroup"` + `aria-checked` |
| 字幕/音频描述 | — | 本产品无叙事音频，暂不适用（交音频同事评估） |
| 输入重映射 | ⏸ | Standard 不强制；保留 WASD/ESC 定制为 P2 |
| 屏幕阅读器完整支持 | ⏸ | Comprehensive 级要求，本期做到"关键流程可读"即可 |

**UX 规格引用要求**：文策渊（design-strategist）产出的 UX 规格须在开头声明「可访问性分级：Standard（见 ART_BIBLE §7）」，并确保交互稿满足上表 ✅ 项。

## 8. 冗余文案清理建议

> 原则：**能用一个图标/一张卡表达的，不用文字；能在帮助里说的，不放在主界面。** 藏起来的说明比摊开的更显质感。

### 8.1 入口页 `#intro` — 逐项处理

| 现有文案 | 处理 | 理由 / 替代 |
|---|---|---|
| `<h1>🌍 新建你的世界</h1>` | **改** | 去 emoji → 「铸造你的世界」（衬线标题，东方感） |
| `<p>选择初始生态环境，工作台会据此生成地形与天空基调。</p>` | **删** | 四张卡已自解释；此句是冗余。如需引导，缩为 12px 一行副标题「择一方天地，起一念造化」（可选） |
| 四个按钮 `🌳草原 / ❄雪原 / 🏜沙漠 / 🌃赛博` | **升级为卡片** | 按第 3、4 节做四联场景卡，图标换统一 SVG 小图标，卡内加氛围词 |
| `世界名称 <input value="未命名世界">` | **改** | 改暗色下划线输入框，占位符「为你的世界命名」，默认值保留但弱化 |
| `<button class="primary">开始建造 →</button>` | **保留并改视觉** | 文案保留，改朱砂→鎏金渐变按钮，去蓝紫 |
| `<p class="tip">引擎已内置本地，无需联网。所有创作自动存于浏览器，可随时导出 GLTF。</p>` | **删** | 技术说明不属于"造世界"的情绪场景；移至「帮助」弹窗末行或设置页 |

### 8.2 加载页 `#loading` — 保留最小信息

| 现有文案 | 处理 |
|---|---|
| `正在加载本地 3D 引擎…` | **保留**（唯一进度信息） |
| `Three.js 已内置，无需联网` | **删**（技术细节，用户无需知道） |

### 8.3 工作台常驻文案 — 精简建议

- 大量 `.hint.xs` 说明（布尔运算、绘画、地形编辑的操作提示）：**首次显示、之后可折叠**，或统一收进「帮助」——避免常驻占屏、破坏简洁。
- `造物精灵` 气泡 `开工啦，造点好东西！`：保留（情感锚点），但随机轮换 3~5 条短句即可，不要堆长句。
- 底部 HUD（FPS/物体/面数/模式/画质）：保留（工具属性），数字用等宽字体对齐。

### 8.4 通用规则

- 单屏功能性文案总量**减少约 40%**；每个区块只保留"标题 + 必要输入/操作"。
- 语气统一为**克制、肯定、无感叹号堆叠**（"开工啦！"类可留作情感点，但正文不用）。
- 不在主界面出现技术名词（Three.js / GLTF / 引擎 / SDK），统一收进帮助或设置。

- ⚠️ **独立渲染视窗**需程基岩确认：单 canvas 拆分为独立 renderer 的性能与内存成本；本规范已按"视窗/UI 同框、样式一致"设计，不依赖特定实现。
- ⚠️ 场景键映射：代码 `BIOMES` 用 `snow` / `urban`，UI 用「雪原 / 赛博」；`cyber` 与 `urban`、`grass` 与代码的对应关系需与程基岩核对，避免卡片点击后加载错误场景。
- ⚠️ `backdrop-filter` 在部分低端设备性能开销大；世界管理页大量叠层时需实测帧率，必要时降级为纯色半透明。
